# license-data-collector

A comprehensive platform and data collection engine for commercial software license intelligence, inventory analysis, and discovery.

## Repository Contents

- **`commercial-license-intelligence/`**: Backend services, discovery and search engines (SearXNG / YaCy / DuckDuckGo fallback chains), bulk upload processors, validation pipelines, and Streamlit frontend dashboard.
- **`Commercial_Licensing_Engine_Architecture.docx`**: System architecture specification.

## Getting Started

Refer to `commercial-license-intelligence/README.md` for local setup, dependencies, environment configuration, and execution instructions.
